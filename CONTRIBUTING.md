# Contributing rules

## Non-negotiable provenance rule

Never edit `source_original` to make Nova fit the Lux model.

If a source statement appears inaccurate, ambiguous or ontologically loaded:

1. preserve it;
2. annotate it;
3. classify the issue;
4. propose an alternative separately.

## Review labels

Use these conceptual review states:

- `unreviewed`
- `heuristic`
- `reviewed`
- `needs_source_check`
- `needs_domain_review`

## Relation discipline

Do not create a strong relation when the source only supports a weaker one.

Prefer:

`co_occurs_with`

over
`precedes`

over
`facilitates`

over
`causes`

unless evidence actually supports the stronger claim.
