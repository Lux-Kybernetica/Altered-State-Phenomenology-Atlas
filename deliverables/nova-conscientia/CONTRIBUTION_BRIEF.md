# Proposition d’enrichissement de la nomenclature Nova Conscientia

## Intention

Ce travail part d’un constat simple : la nomenclature Nova v1 contient déjà beaucoup de distinctions utiles, mais son **arbre pédagogique** mélange plusieurs dimensions logiques différentes.

Les six familles actuelles restent très bonnes comme interface de lecture :

- États & lucidité
- Transitions
- Phénomènes perceptifs
- Navigation
- Obstacles
- Sécurité

Le problème n’est pas l’interface. Le problème apparaît seulement lorsqu’on veut exploiter les données pour comparer des expériences, construire un graphe, faire de la recherche ou relier plusieurs traditions.

La proposition consiste donc à **ne pas remplacer l’arbre**, mais à ajouter une couche structurée sous l’interface.

---

## 1. Ce qui a été fait

### Revue intégrale de la v1

Les **92 termes** de la nomenclature ont été relus individuellement en conservant le texte source séparément de toute annotation proposée.

Les annotations ne réécrivent pas Nova :

```text
source_original
    = ce que dit Nova

annotation
    = ce que le modèle analytique ajoute
```

### Revue des relations

Le mécanisme de « résonances » de la v1 crée des liens lorsqu’un terme apparaît dans la fiche d’un autre, puis rend ces liens symétriques.

C’est excellent pour une navigation pédagogique, mais une citation lexicale n’est pas forcément une relation sémantique.

Les **97 paires de résonance uniques** ont donc été relues :

- 92 paires produisent au moins une relation sémantique utile ;
- 5 paires ont été volontairement rejetées comme artefacts lexicaux/contextuels ;
- 96 arêtes sémantiques ont finalement été conservées, certaines paires portant plusieurs relations légitimes.

Exemples de relations désormais distinguables :

```text
DISTINGUISH_FROM
PRECEDES
CO_OCCURS_WITH
FACILITATES
INHIBITS
IS_A
PART_OF
MAY_TRIGGER
MAY_CONTAIN
ASSOCIATED_WITH
```

## 2. Le principal enrichissement proposé : un modèle multi-axial

Une même expérience peut simultanément être :

- un phénomène perceptif ;
- située pendant une transition ;
- vestibulaire ;
- affecter la localisation du soi ;
- réduire la motricité ;
- survenir avec une forte lucidité.

Un arbre unique ne peut pas exprimer cela sans dupliquer les termes.

La proposition ajoute donc plusieurs axes indépendants.

### Type

Ce que l’objet est principalement :

```text
state
phenomenon
transition
action
obstacle
safety
concept
situation
condition
```

### Phase

Quand il survient :

```text
wake
sleep_onset
awakening
threshold
separation
experience
return
post_experience
```

### Modalité

Comment il est perçu :

```text
visual
auditory
somatosensory
proprioceptive
vestibular
interoceptive
affective
cognitive
temporal
social_presence
```

### Selfhood / embodiment

Quel aspect du soi corporel est affecté :

```text
self_location
body_ownership
first_person_perspective
agency
body_boundaries
```

### Cognition

```text
meta_awareness
reasoning_clarity
memory_continuity
goal_maintenance
executive_control
attention_stability
temporal_continuity
reality_monitoring
```

### Motricité

```text
normal
reduced
immobility
atonia
perceived_paralysis
involuntary_movement
motor_effort
```

### Fonction d’une action

Une action comme « Se calmer » n’a pas la même fonction que « Retour volontaire » ou « Ancrage de mémoire ».

Les actions peuvent donc être décrites par leur fonction opérationnelle plutôt que d’être regroupées sous un simple tag cognitif.

## 3. Séparer phénomène, interprétation et hypothèse

C’est probablement l’amélioration la plus importante pour un projet destiné à accueillir plusieurs sensibilités.

Une fiche peut contenir simultanément :

1. une observation phénoménologique ;
2. une définition opératoire ;
3. une interprétation ;
4. une hypothèse causale ou ontologique.

Ces quatre niveaux ne devraient pas avoir le même statut.

Exemple abstrait :

```text
"sensation de vibration interne"
→ observation phénoménologique

"souvent proche d'une transition"
→ association rapportée

"désaccouplement de la conscience et du soma"
→ interprétation de mécanisme
```

Le modèle porte donc le statut épistémique **sur chaque assertion**, pas seulement sur le terme entier.

---

## 4. Embodiment : une dimension qui mérite d’être explicitée

La littérature scientifique sur les expériences autoscopiques et la conscience corporelle distingue notamment :

- la localisation du soi ;
- la propriété du corps ;
- la perspective à la première personne ;
- l’agentivité.

Ces dimensions permettent de mieux différencier :

- Double localisation ;
- Corps de sortie ;
- Décrochage ;
- Flottement / Rotation / Traction ;
- Sortie partielle / complète.

Elles sont utiles indépendamment de la position ontologique adoptée.

---

## 5. Une couche de sources plutôt qu’une guerre d’interprétations

Le projet contient désormais trois couches externes distinctes.

### Monroe / Gateway

Les termes et techniques Gateway sont conservés comme concepts propres au programme.

Un Focus level n’est jamais déclaré identique à un terme Nova.

Exemples :

- vibrations perçues ↔ État vibratoire : forte proximité phénoménologique ;
- log-rolling ↔ Rotation volontaire : forte proximité opérationnelle ;
- Focus 10 ↔ Endormissement conscient : similarité fonctionnelle partielle, mais unités conceptuelles différentes ;
- Focus 21 / 27 : pas d’équivalent Nova direct imposé.

### Vieira / Projeciologia

Même discipline :

- `estado vibracional` ↔ État vibratoire : forte proximité phénoménologique ;
- `semiprojeção` ↔ Sortie partielle : proximité structurelle ;
- `decolagem do psicossoma` ↔ Décrochage : proximité transitionnelle avec asymétrie ontologique ;
- `psicossoma` ↔ Corps de sortie : seulement chevauchement partiel, jamais identité.

### Littérature scientifique

Les études scientifiques sont liées selon leur rôle :

```text
experimental_analogue
mechanistic_context
clinical_context
phenomenology_context
measurement_precedent
operationalization_support
alternative_explanation
```

Ainsi, une étude de self-location n’est pas marquée comme « explication définitive de l’OBE » et une tradition ne devient pas « validée » parce qu’elle décrit un phénomène ressemblant à un effet de laboratoire.

## 6. Premiers résultats comparatifs utiles

Une première matrice Nova × Monroe × Vieira fait apparaître quelques convergences suffisamment précises pour devenir des **questions de recherche**, et non des preuves :

### État vibratoire

Plusieurs traditions décrivent un ensemble de sensations internes de vibration / oscillation / électrisation dans des contextes de transition.

Question mesurable :

> Dans quelle proportion d’expériences de transition ces sensations apparaissent-elles, à quel moment et chez quels pratiquants ?

### Décrochage

Plusieurs systèmes possèdent un concept de bascule ou de changement de localisation/perception entre état corporel ordinaire et expérience de séparation.

Question mesurable :

> Peut-on identifier un noyau phénoménologique reproductible indépendamment du vocabulaire appris ?

### Sortie partielle

Plusieurs descriptions utilisent des transitions partielles ou progressives, parfois membre par membre.

Question mesurable :

> La séquence corporelle rapportée dépend-elle de la technique apprise, ou apparaît-elle aussi chez des sujets naïfs ?

## 7. Un protocole pour les témoignages

Un schéma de rapport a été construit pour éviter un problème classique : **apprendre au témoin les mots qu’on espère ensuite retrouver dans son témoignage**.

Le protocole distingue :

```text
DESCRIPTION BRUTE
↓
CODAGE / MAPPING NOVA
↓
INTERPRÉTATION
```

Il enregistre également :

- contexte d’induction ;
- ordre temporel ;
- confiance du souvenir ;
- délai avant le récit ;
- familiarité préalable avec Monroe / Vieira / Nova ;
- vocabulaire montré avant le récit ;
- questionnement ouvert ou dirigé ;
- confiance du mapping analytique.

Cela rend possible une vraie étude de fréquence et de séquences sans transformer les témoignages en questionnaire auto-réalisateur.

## 8. Phosphenic Pathway : contribution expérimentale séparée

Un premier Pathway phosphénique a été modélisé :

```text
Phosphènes
  ↓
Hypnagogie / images
  ↓
[scène immersive possible]
  ↓
Zone de bascule
  ↓
[marqueurs optionnels]
  ├ vibration
  ├ bourdonnement
  ├ flottement
  ├ rotation
  ├ traction
  └ stase
  ↓
Décrochage
  ↓
[sortie partielle / complète possible]
```

Il est volontairement stocké **hors de l’ontologie Nova**.

C’est une hypothèse de séquence expérimentale qui doit pouvoir être confirmée, ramifiée ou abandonnée par les données.

---

## 9. Ce qui peut être utile immédiatement à Nova

Même sans adopter toute l’architecture, cinq contributions peuvent être intégrées indépendamment :

### A. Relations typées

Remplacer ou compléter les « résonances » par des liens dont la signification est connue.

### B. Axes supplémentaires invisibles dans l’interface

Conserver l’arbre actuel tout en permettant des filtres :

- vestibulaire ;
- auditif ;
- phase de retour ;
- self-location ;
- mémoire ;
- motricité ;
- etc.

### C. Provenance / statut épistémique

Permettre d’afficher :

```text
Observation
Terme opératoire
Interprétation
Hypothèse
Source traditionnelle
Source scientifique
```

### D. Comparateur de traditions

Une même fiche pourrait proposer :

```text
Nova
Monroe
Vieira
Science
```

sans fusionner leurs modèles.

### E. Formulaire de témoignage structuré

Ce serait probablement la contribution ayant le plus de valeur à long terme : la nomenclature deviendrait progressivement un **instrument de collecte de données**.

---

## 10. Ce qui n’est volontairement pas proposé

- réécrire les 92 définitions sans discussion avec Nova ;
- imposer un modèle neuroscientifique ;
- imposer un modèle énergétique ou projectiologique ;
- appeler une convergence « validation » ;
- rendre la nomenclature plus compliquée à utiliser pour le public ;
- publier ou redistribuer des contenus tiers sans clarification des droits.

---

## Conclusion

La v1 fonctionne déjà comme **langage partagé et carte pédagogique**.

La contribution proposée consiste à lui donner une deuxième vie possible :

> **interface pédagogique en surface, modèle de connaissance et instrument de recherche en profondeur.**

L’objectif n’est pas de remplacer Nova Conscientia, mais de rendre ce qui existe déjà plus interopérable, plus mesurable et plus difficile à confondre avec ses propres interprétations.
