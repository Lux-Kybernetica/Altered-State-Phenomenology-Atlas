# Nova Conscientia — contribution package v0.1

This directory is the **human-facing handoff layer** of the research workspace.

It deliberately avoids requiring Nova Conscientia to adopt the full internal Lux architecture. The goal is to offer reusable improvements that can be integrated incrementally into the existing nomenclature and Skill Tree.

## Start here

1. `CONTRIBUTION_BRIEF.md` — what was studied, what was found, and what is being offered.
2. `IMPLEMENTATION_PLAN.md` — a low-disruption path from the current Skill Tree to a richer model.
3. `DATA_DICTIONARY.md` — the proposed multi-axial fields and relation vocabulary in plain language.
4. `OUTREACH_DRAFT.md` — a short, non-grandiose way to present the contribution.

## What already exists in the repository

The package is backed by working research/data artifacts rather than a conceptual memo alone:

- **92 / 92 Nova v1 terms manually reviewed**;
- **97 / 97 original lexical resonance pairs semantically reviewed**;
- **96 accepted typed relations**, with five original resonance pairs explicitly rejected as lexical/context artifacts;
- a multi-axial semantic model covering type, perceptual modality, temporal phase, selfhood, cognition, action function and motor state;
- assertion-level epistemic status;
- an experimental `Phosphenic Pathway` kept separate from the core ontology;
- structured experience-report schemas and an anti-contamination reporting protocol;
- Monroe / Gateway and Vieira / Projectiology crosswalks that forbid automatic identity mappings;
- a first cross-tradition convergence matrix;
- a scientific evidence layer linking 11 peer-reviewed studies to 10 Nova concepts by explicit evidence role.

## Core principle

**Preserve Nova's wording and interface; enrich the model underneath.**

The existing six-family Skill Tree can remain the public pedagogical view. The proposed model adds orthogonal metadata and typed relationships without forcing the UI to become an ontology diagram.

## What this package does not ask Nova to accept

- no metaphysical position;
- no claim that Monroe, Vieira and Nova describe identical realities;
- no claim that neuroscientific analogues exhaust spontaneous experiences;
- no requirement to adopt the Phosphenic Pathway;
- no requirement to replace existing definitions;
- no requirement to make the underlying data model visible to casual users.

The contribution is useful even if Nova adopts only stable IDs, typed relations and evidence/provenance fields.
