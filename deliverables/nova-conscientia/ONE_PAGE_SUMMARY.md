# Nova Conscientia — proposition d’enrichissement en une page

Votre Skill Tree v1 fonctionne déjà très bien comme **carte pédagogique**.

La contribution proposée consiste à lui ajouter, sans remplacer l’interface actuelle, une couche de données permettant d’en faire aussi un **modèle de connaissance et un instrument de recherche**.

## Travail déjà réalisé

- **92 / 92 termes** relus en conservant la source originale séparément ;
- **97 / 97 résonances** examinées sémantiquement ;
- **96 relations typées** conservées ;
- modèle multi-axial : type, phase, modalité, selfhood, cognition, motricité, fonction d’action ;
- statut épistémique au niveau de chaque assertion ;
- crosswalks prudents avec Gateway/Monroe et Vieira/Projeciologia ;
- première matrice de convergences inter-traditions ;
- **11 études scientifiques** reliées à 10 concepts Nova par rôle explicite ;
- protocole et formulaire de témoignage non-directif ;
- premier Pathway expérimental séparé de l’ontologie.

## L’idée centrale

Un terme ne devrait pas être obligé de vivre dans une seule case.

Exemple : un phénomène peut être simultanément :

```text
vestibulaire
+ seuil d’endormissement
+ changement de self-location
+ spontané
+ associé à une transition
```

sans être dupliqué dans cinq branches.

L’arbre Nova reste la vue publique. Les axes supplémentaires vivent sous le capot.

## Deuxième principe : ne pas confondre description et interprétation

Le modèle sépare :

```text
OBSERVATION
DÉFINITION OPÉRATOIRE
INTERPRÉTATION
HYPOTHÈSE
```

Cela permet d’accueillir des lectures différentes sans dégrader la précision phénoménologique.

## Relations typées

Les résonances restent utiles pour naviguer.

Pour la recherche, elles peuvent être complétées par :

```text
DISTINGUISH_FROM
PRECEDES
CO_OCCURS_WITH
FACILITATES
INHIBITS
MAY_TRIGGER
IS_A
PART_OF
```

Chaque lien porte une base et une provenance.

## Comparaison des traditions

Gateway et Vieira sont traités comme **systèmes externes**, jamais comme dictionnaires d’équivalences.

Exemple :

```text
Nova : État vibratoire
Monroe : perceived vibrations
Vieira : estado vibracional
Science : phénoménologie / mécanismes à tester
```

Le chevauchement devient une question de recherche, pas une validation métaphysique.

## Le plus gros potentiel : les témoignages

Le formulaire proposé demande :

1. récit libre ;
2. chronologie ;
3. clarifications ouvertes ;
4. verrouillage du récit ;
5. seulement ensuite codage Nova.

Il enregistre également la familiarité préalable avec les traditions afin de distinguer **convergence phénoménologique** et **vocabulaire culturel partagé**.

Avec suffisamment de rapports, il devient possible de mesurer :

- fréquence des phénomènes ;
- ordre des événements ;
- branches de trajectoire ;
- effets des techniques ;
- différences naïfs / pratiquants entraînés ;
- phénomènes présents ou absents avant une transition.

## Trois questions prioritaires déjà identifiées

1. Les **vibrations** prédisent-elles réellement une transition, ou surtout l’apprentissage d’une tradition ?
2. Le **Décrochage** possède-t-il un noyau de self-location identifiable indépendamment du rêve et de la paralysie du sommeil ?
3. Les **sorties partielles** suivent-elles des séquences spontanées ou la forme précise de la technique enseignée ?

## Ce qui peut être adopté indépendamment

Nova peut prendre seulement :

- les relations typées ;
- les axes embodiment / cognition / motricité ;
- la provenance ;
- les sources scientifiques ;
- le formulaire de témoignage ;
- les crosswalks ;
- ou l’ensemble.

Aucune refonte totale n’est nécessaire.

> **Interface pédagogique en surface, modèle de connaissance et instrument de recherche en profondeur.**
