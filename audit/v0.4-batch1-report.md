# NC × Lux — Révision v0.4 · Batch 1

**18 termes désormais relus manuellement (10 pilotes + 8 nouveaux). 74 restent à réviser.**

## Ce que ce batch a révélé

- `situation` doit être un type propre.
- `condition` est nécessaire pour des objets comme **Fenêtre de sortie**.
- `awakening` est nécessaire pour ne pas mélanger hypnagogie et hypnopompie.
- La motricité doit être un axe distinct : atonie, paralysie perçue, sursaut, effort moteur.
- Les heuristiques lexicales ont tendance à surclasser les modalités ; la révision humaine les resserre.

## Entrées révisées dans ce batch

### Projection lucide
- Types : state, situation
- Modalités : visual, cognitive
- Phases : separation, experience
- Selfhood : self_location, first_person_perspective, agency
- Motricité : —
- Note : La catégorie Nova « état / situation » mérite un type situation propre plutôt qu’un rabattement artificiel vers concept.

### Paralysie du sommeil
- Types : phenomenon, transition
- Modalités : somatosensory, affective
- Phases : threshold
- Selfhood : —
- Motricité : atonia, perceived_paralysis
- Note : Les images, sons et présences sont décrits comme accompagnements possibles ; ils ne définissent pas à eux seuls la modalité principale du phénomène.

### Hypnopompie
- Types : transition, phenomenon
- Modalités : visual, auditory, somatosensory, social_presence
- Phases : awakening
- Selfhood : —
- Motricité : —
- Note : Correction majeure : l’hypnopompie relève du réveil, pas de l’endormissement.

### Sortie complète
- Types : transition, situation
- Modalités : visual, proprioceptive, vestibular
- Phases : separation, experience
- Selfhood : self_location, first_person_perspective, agency
- Motricité : —
- Note : La source décrit à la fois un passage et une situation vécue avec point de vue externe et mobilité.

### Réponse de sursaut
- Types : phenomenon, obstacle
- Modalités : somatosensory
- Phases : threshold, separation, return
- Selfhood : —
- Motricité : involuntary_movement
- Note : Le caractère moteur doit être représenté par un axe séparé, pas noyé dans les modalités perceptives.

### Fenêtre de sortie
- Types : condition
- Modalités : temporal
- Phases : threshold, separation
- Selfhood : —
- Motricité : —
- Note : Ce terme désigne une condition/opportunité temporelle, pas une transition en soi.

### Pression émotionnelle
- Types : phenomenon
- Modalités : affective, interoceptive
- Phases : threshold, return
- Selfhood : —
- Motricité : —
- Note : La catégorie source « présence perçue » ne doit pas entraîner automatiquement social_presence : la définition porte ici sur la montée émotionnelle.

### Amplification sonore
- Types : phenomenon
- Modalités : auditory
- Phases : threshold, experience
- Selfhood : —
- Motricité : —
- Note : Réduction de la surclassification heuristique : le noyau du terme est auditif.
