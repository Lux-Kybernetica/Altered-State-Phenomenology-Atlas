# NC × Lux — Transitions review batch 2

## Scope

Manual review of the seven remaining entries in the Nova Conscientia **Transitions** family:

- Endormissement conscient
- Réveil en zone de bascule
- Stase
- Bourdonnement intracrânien
- Sortie partielle
- Retour brusque
- Retour progressif

Combined with the eight transition-family entries already reviewed in the pilot/batch 1, this completes semantic review coverage of all **15 / 15** source terms in `data/source/terms-transitions.json`.

## Main modelling decisions

### Endormissement conscient
Represented as `transition + concept`, not merely a state. The body-asleep / consciousness-active wording is preserved as Nova's operational framing and not flattened into a neutral phenomenological observation.

### Réveil en zone de bascule
Represented as `transition + situation`, with phases `awakening + threshold`. Motor states `immobility + atonia` are explicit because the source describes a clear mind with a body in stasis.

### Stase
Represented primarily as `state + condition`, despite its placement by Nova inside the Transitions family. This avoids making source navigation categories identical to semantic types. It is explicitly distinguished from sleep paralysis, as Nova itself does.

### Bourdonnement intracrânien
Represented primarily as an auditory phenomenon, with a secondary somatosensory component because pressure is described. The source-supported relation to `Décrochage` is preserved as a frequent precedence report, not a causal law.

### Sortie partielle
Represented as `transition + situation`, with explicit embodiment dimensions `body_ownership + body_boundaries`. The phrase `corps de sortie` remains an operational/perceptual construct rather than an ontological assertion.

### Retour brusque
Description and purported triggers are split. The phenomenological core is a sudden return/reintegration; fear, excitement, surprise, crying and instability are stored as source-reported associations rather than silently upgraded to demonstrated causes.

### Retour progressif
The observable sequence (scene loss → bodily sensations return → awakening) is separated from the operational interpretation (`replongée dans le corps`, `conscience qui réatterrit`).
