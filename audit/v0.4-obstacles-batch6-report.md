# NC × Lux — Review batch 6: Obstacles

## Scope

Manual review of all **13 Nova obstacle entries**.

## Main finding
No new top-level axis was required. The obstacle family decomposes cleanly across the existing model:

- cognition / lucidity loss;
- attention instability;
- motor interference;
- affect escalation;
- perceptual instability;
- memory discontinuity;
- interpretive overreach.

`obstacle` therefore remains a functional type rather than a separate phenomenological dimension.

## Important distinctions

- `Endormissement` is only an obstacle relative to Nova's practical goal of maintaining lucidity; sleep itself is not treated as intrinsically problematic.
- `Hypercontrôle` involves executive control in excess; cognitive dimensions identify the function involved, not whether it is weak or strong.
- `Effort musculaire` is an action classified as an obstacle in the threshold/separation protocol.
- `Peur de la zone de bascule` separates the observation of fear from Nova's broader claim that the relevant phenomena are benign. That general safety claim is not encoded as a universal fact.
- `Fragmentation` may reflect discontinuity in experience, recall, or both; the current data do not justify collapsing these possibilities.
- `Amnésie de retour` separates observed recall loss from the proposed explanation involving movement/distraction.
- `Confusion interprétative` strongly supports the project's SOURCE / ANALYSIS / PROPOSAL separation.
