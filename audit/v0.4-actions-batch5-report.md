# NC × Lux — Review batch 5: Navigation / actions

## Scope

Manual review of the **18 navigation/action entries not previously covered**, plus alignment of the existing `Lâcher-prise` pilot annotation with the new action model.

## Main finding: actions need functional semantics
The generic type `action` is insufficient to distinguish what an action is for. This batch introduced optional `action_functions[]` with controlled values:

- `stabilization`
- `affect_regulation`
- `attention_regulation`
- `intention_control`
- `separation`
- `navigation`
- `interaction`
- `epistemic_monitoring`
- `return`
- `memory_consolidation`
- `integration`

This axis describes *function*, while `types[]` continues to describe logical kind.

## Important distinctions

- `Orientation` = choose a destination or goal; `Déplacement` = execute movement.
- `Rotation` = perceived phenomenon; `Rotation volontaire` = deliberate strategy acting on that phenomenon.
- `Ancrage de mémoire` = recall-preservation procedure; `Ancrage post-expérience` belongs to safety and concerns return to ordinary daily orientation.
- `Suspension du jugement` and `Test de cohérence` are epistemic practices, not claims about ontology.
- `Communication` describes an interaction attempt without inferring the nature of any interlocutor.
- The causal explanation attached to `Ancrage de mémoire` (motor activation erasing memory traces) is separated from the practical procedure and kept at interpretation level.
