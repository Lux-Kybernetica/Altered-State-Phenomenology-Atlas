# NC × Lux v0.5 — Typed relation review complete

The full set of **97 unique Nova v1 lexical resonance pairs** has now received an explicit semantic-review decision.

## Result

- Original Nova lexical resonance pairs: **97**
- Pairs producing at least one accepted semantic edge: **92**
- Pairs deliberately producing no semantic edge: **5**
- Accepted typed edges: **96**

There are more edges than accepted pairs because one lexical pair can encode several legitimate semantic relations:

- `Flottement ↔ Décrochage`: distinction + possible temporal precedence + possible co-occurrence;
- `Stase ↔ Sortie partielle`: distinction + explicit precedence.

## Explicit no-edge decisions

Five lexical resonances were rejected as semantic edges because the source link was produced by substring/context mechanics rather than a stable conceptual relation:

1. Clarté mentale ↔ Endormissement conscient
2. Confusion mentale ↔ Lucidité
3. Dissolution des frontières ↔ Lucidité
4. Lâcher-prise ↔ Zone de bascule
5. Lucidité ↔ Rotation volontaire

See `data/v0.5/resonance-no-semantic-edge.json` for rationale.

## Interpretation

This is the first point where the NC × Lux model genuinely ceases to be a decorated version of the original skill tree. Nova's lexical navigation layer is preserved, but semantic graph membership is now a reviewed decision with explicit relation type and provenance.
