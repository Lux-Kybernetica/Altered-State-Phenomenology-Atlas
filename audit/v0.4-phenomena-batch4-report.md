# NC × Lux — Review batch 4: Phénomènes perceptifs

## Scope

Manual semantic review of the **17 perceptual-phenomena entries not already covered** by the pilot or batch 1.

## Main findings

### 1. `phénomène somatique` is too broad analytically
Several source entries are better represented through explicit modality axes:

- Balancement / Chute interne → vestibular + proprioceptive
- Lourdeur → somatosensory + proprioceptive
- Dissociation sensorielle → somatosensory + proprioceptive

This does not replace the Nova category; it adds an analytical layer.

### 2. Some phenomena are primarily about selfhood, not sensory modality

- Double localisation → self_location + first_person_perspective
- Dissolution des frontières → self_location + body_boundaries
- Corps de sortie → body_ownership + body_boundaries
- Scène immersive → self_location + first_person_perspective

This confirms the usefulness of `selfhood_dimensions[]`.

### 3. Source-category mismatches must remain visible
Nova currently places both `Pression émotionnelle` and `Distorsion du temps` under the category `présence perçue`, although their definitions respectively describe affective/interoceptive and temporal phenomena. We preserve the source category but do not propagate it into the Lux semantic classification.

### 4. Perception and interpretation remain separate
`Présence perçue` is modeled as `social_presence` without implying an external entity. `Corps de sortie` is modeled as a perceived body configuration; the source itself warns that this is not ontological proof.

### 5. Absence can itself be a perceptual state
`Écran noir` is represented within the visual modality even though its defining content is *absence of image*. This matters for future coding: modality presence and modality content must not be conflated.
