# Vieira / Projectiology crosswalk

The Vieira / Projeciologia layer is an **external framework alignment** built from source material rather than from Nova's own parenthetical equivalence labels.

## Epistemic rule

A Projectiology term can be useful in three different ways that must not be collapsed:

1. **phenomenological description** — what a practitioner reports sensing;
2. **operational/procedural concept** — how the framework structures a transition or technique;
3. **framework ontology** — psychosome, energossoma, extraphysical dimensions, vehicle coincidence, etc.

Only the first two normally support Nova crosswalks. The third remains source context unless independently supported elsewhere.

## Current v0.1

### Strong operational alignment

- `vieira.estado_vibracional` → `nova.etat_vibratoire`
- `vieira.semiprojection` → `nova.sortie_partielle`
- `vieira.catalepsia_projetiva` → `nova.paralysie_du_sommeil`

### Strong but ontologically asymmetric transition

- `vieira.decolagem_psicossoma` → `nova.decrochage`

The two describe a comparable transition structure, but Projectiology states the transition in terms of a psychosome while Nova can remain at the level of perceived self-location / center-of-perception change.

### Deliberately weak alignment

- `vieira.psicossoma` → `nova.corps_de_sortie`

This is only `partial_overlap`. Nova's node is a perceived alternative body and explicitly rejects ontological proof; Projectiology's psicossoma is a framework-defined vehicle. Identity would destroy that distinction.

### Compound mapping

- `vieira.projecao_semiconsciente` → `nova.semi_lucidite` + `nova.reve_lucide`

Projectiology mixes a lucidity level and dream-like/projective category in a way Nova deliberately separates. The crosswalk therefore points to two NC dimensions instead of pretending a one-to-one translation exists.

### No direct equivalent

- `vieira.ballonnement`

The swelling/inflation embodiment sensation is specific enough that Nova currently has no canonical counterpart. This gap is retained rather than aesthetically repaired.

## Source typing

`sources/vieira-projectiology-claims-v0.1.json` separates:

- framework definitions that can support phenomenological comparison;
- interpretive mechanism claims;
- metaphysical claims.

Claims about psychosome/energossoma/holossoma existence are not imported as Nova facts.

## Institutional self-description

IIPC and the Vieira tradition describe Projeciologia/Conscienciologia as sciences operating under a consciousness paradigm. Lux records that self-description as source framing. It is not, by itself, independent scientific validation of the framework's ontological claims.
