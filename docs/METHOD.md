# Method — What we are doing

## 1. Preserve before interpreting

The original Nova Conscientia material is treated as a source layer. We do not silently correct wording, merge concepts, rewrite definitions, or replace their taxonomy with ours.

Every enrichment must remain distinguishable from the source.

## 2. Move from a tree to a multi-axial model

Nova's interface is pedagogically useful as a tree, but the underlying concepts are not all members of the same logical hierarchy.

Examples:

- an **state** describes the subject's condition;
- a **transition** describes temporal/process position;
- a **phenomenon** describes experiential content;
- an **action** describes agency;
- an **obstacle** describes functional role;
- **safety** is a practice layer.

Therefore, Lux models concepts on several independent axes instead of forcing every term into one exclusive branch.

## 3. Separate perceptual modality from process phase

A term can be, for example:

- vestibular + proprioceptive in modality;
- threshold + separation in phase;
- phenomenon in type.

This prevents terms such as rotation, traction or floating from being reduced to a generic 'somatic' bucket.

## 4. Add selfhood / embodiment dimensions

Some SHC-related experiences involve more than sensory content. They affect:

- self-location;
- body ownership;
- first-person perspective;
- agency;
- body boundaries.

These dimensions are represented separately when relevant.

## 5. Separate motor state from perception

Motor phenomena require their own axis. Current examples include:

- atonia;
- perceived paralysis;
- involuntary movement;
- motor effort.

This avoids classifying a motor condition as if it were merely a sensory modality.

## 6. Put epistemic status on assertions

A single source entry can contain several different kinds of statements at once.

Example pattern:

- 'internal vibrations are perceived' → phenomenological description;
- 'often associated with dissociation' → source-supported association;
- 'causes separation' → causal interpretation/hypothesis unless demonstrated.

For this reason, epistemic status belongs primarily to **assertions**, not to entire concepts.

## 7. Typed relations, not generic resonances

Nova v1 creates 'resonances' when one term appears textually in another term's entry. This is useful for navigation, but it does not specify what kind of relationship exists.

Lux progressively replaces this ambiguity with typed relations such as:

- `part_of`
- `precedes`
- `follows`
- `co_occurs_with`
- `facilitates`
- `inhibits`
- `distinguish_from`

Proposed relations remain explicitly marked as proposed until supported.

## 8. Delay the graph

We deliberately do **not** generate a polished knowledge graph yet.

A beautiful graph built on unstable semantics is simply a more decorative error.

The graph comes after manual review of the vocabulary and relation model.
