# Nova Conscientia source layer

The canonical current term files under `data/current/v0.4/terms/` embed the exact extracted Nova fields under `source_original`.

This directory stores compact source-level helpers: the six original families and the v1 resonance edge list.

Original public page: https://novaconscientia.com/nc-skill-tree.html

The raw HTML snapshot is deliberately not committed while reuse/publication permissions remain unresolved. A private local snapshot is retained separately for reproducibility.
